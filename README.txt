ROSC Workforce Intelligence Platform website
====================
Standalone static website for the ROSC Workforce Intelligence Platform, using an ivory / black / muted-gold aesthetic.
It does not connect to or modify the existing survey application or database.

Before publishing:
1. Replace the placeholder contact email in index.html with your confirmed business email before publishing.
2. Verify the ROSC Pulse URL and review all pilot claims/deliverables.
3. Create a NEW GitHub repository for these files.
4. Import that repository into Vercel as a NEW project. This is separate from your existing Claude-built app.
5. No framework/build command is needed for this plain HTML/CSS/JS site.
6. Use the free Vercel-provided URL to start; a custom domain can be added later.

Scoring and benchmark capabilities are described as in development where appropriate.
